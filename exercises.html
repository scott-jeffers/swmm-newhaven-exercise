SWMM step by step: from one subcatchment to a catch-basin reactor

Five short exercises that build on each other. Each one tells you exactly what to click and type, shows the result you should get, and has a solution .inp to download if you get stuck.

Before you start

  1. Install EPA SWMM 5.2 from the EPA SWMM page (Windows). Any 5.2.x release works.
  2. Set the defaults once: Project ▸ Defaults. On the Node/Link tab set Flow Units = CFS, Link Offsets = DEPTH, Routing Model = Dynamic Wave. On the Subcatchments tab set Infiltration Model = HORTON. Tick Save as defaults for all new projects.
  3. Know the browser: the Data tab on the left lists every object type. Double-click any object (on the map or in the list) to open its property editor.
Every solution file opens directly in SWMM: File ▸ Open, pick the .inp, then click the lightning-bolt Run button.

1 · One subcatchment

Turn rainfall into runoff for a single 5-acre lot and see how imperviousness changes the hydrograph.

3 · Adding water quality (TSS)

Let dirt build up on the land for a week, then wash it off in the storm and follow it to the outfall.

PollutantsLand usesBuildupWashoffPollutographsMass balance
  1. Start from Exercise 2 (30" C3).
  2. Add a pollutant: Data ▸ Quality ▸ Pollutants ▸ +. Name TSS, Units MG/L. Leave all concentrations at 0.
  3. Add a land use: Data ▸ Quality ▸ Land Uses ▸ +. Name Residential.
    • Buildup tab: Function EXP, Max. Buildup 50, Rate Constant 0.5 (1/day), Normalizer AREA (lb/ac).
    • Washoff tab: Function EXP, Coefficient 1.0, Exponent 1.5.
  4. Assign it: open each subcatchment, click Land Uses and give Residential 100%. You can select all three and use Edit ▸ Group Edit.
  5. Give the dirt time to build up: Options ▸ Dates: Antecedent Dry Days = 7. Extend the end time to 23:59.
  6. Run, then graph Node OUT1 · TSS together with Node OUT1 · Total Inflow. Look at the Runoff Quality and Quality Routing continuity in the status report.

✓ Check your results

About 291 lb of TSS washes off and reaches the outfall. The concentration peaks at about 200 mg/L just after the rain peak: the "first flush".

Ask the class: what happens to the washoff if you change Antecedent Dry Days to 1?

4 · The batch reactor: a storage node with treatment

A closed tank with no inflow or outflow is a textbook batch reactor. SWMM should reproduce first-order settling exactly. It does, if you write the treatment expression the right way.

Storage unitsInitial concentrationTreatment expressionsDT vs HRT
C(t) = C0 · e−k t,   C0 = 100 mg/L, k = 0.5 /hr
  1. New project. Add a Storage Unit TANK: Invert El. 100, Max. Depth 6, Initial Depth 3, Storage Curve FUNCTIONAL with Coefficient 0, Exponent 0, Constant 100. That makes a 10 × 10 ft tank holding 3 ft of water.
  2. Give it an exit that never flows: add outfall OUT1 (Invert 95), and a conduit C1 TANK → OUT1, 1 ft circular, 50 ft long, Inlet Offset = 4 ft. The pipe sits above the 3-ft water surface, so the tank is closed.
  3. Pollutant with a starting concentration: add TSS (MG/L) with Init. Concen. = 100. The initial concentration fills every node, including the tank.
  4. Treatment: open TANK ▸ Treatment ▸ TSS, and enter 
    C = TSS * EXP(-0.5*DT/3600)
    DT is the routing time step in seconds, so each step applies e−k·Δt. Over time that compounds to exactly e−kt.
  5. Options: end time 12:00, reporting step 0:10. Run, then graph Node TANK · TSS.
  6. Now try the tempting version: change the expression to C = TSS * EXP(-0.5*HRT) and run again (file Ex4b).

✓ Check your results

With DT/3600: 100 → 60.7 → 36.8 → 22.3 mg/L at 1, 2 and 3 hr, matching the analytic curve. The pollutant's built-in Decay Coeff. = 12 /day (= 0.5 /hr) gives the same curve (Ex4c).

The HRT pitfall. SWMM evaluates a treatment expression at every routing step on the water already in the node. HRT is the age of that water, not the length of the step. So exp(−k·HRT) is applied again and again, and the tank drops to zero within the first hour. Use exp(−k·DT/3600) (or Kdecay) for first-order decay. Our West Haven street-cleaning scenarios used the HRT form; see the note on the study report.

5 · Catch basins as reactors: converting junctions to storage nodes

A real catch basin has a sump below the outlet pipe that always holds water. Model it by turning each junction into a storage node with a 2-ft sump and the treatment from Exercise 4.

Converting nodesConduit offsetsDead storageReactors in series
  1. Start from Exercise 3.
  2. Convert J1, J2, J3 to storage units. Right-click a junction and choose Convert To ▸ Storage Unit. If your SWMM version doesn't offer it, delete the junction, add a Storage Unit with the same name in the same place, and reconnect the conduits.
  3. Drop the floor 2 ft to make the sump. For each storage unit: Invert El. = old invert − 2 (J1 98, J2 96, J3 94), Max. Depth 8, Initial Depth 2 (the sump starts full of water), Storage Curve FUNCTIONAL, Constant 16 (a 4 × 4 ft box).
  4. Keep the pipes where they were with offsets (Link Offsets = DEPTH): C1 Inlet Offset 2, Outlet Offset 2; C2 Inlet 2, Outlet 2; C3 Inlet 2 (outlet stays 0 at the outfall).
  5. Add treatment to each storage unit: TSS: C = TSS * EXP(-0.5*DT/3600).
  6. Run, then graph Node J1 · TSS and OUT1 · TSS, and compare Mass Reacted in the Quality Routing Continuity with Exercise 3 (0 lb).

✓ Check your results

During the storm, water flows through each 32 ft³ sump in seconds. Settling barely acts: only about 1.2 lb of 291 lb (0.4%) reacts. After the storm, the dirty water left in each sump is a batch reactor. J1's TSS falls by e−0.5·2 ≈ 0.37 every 2 hours, exactly as in Exercise 4.

Ask the class: what parameter, other than k, would make a sump trap more during the storm? (Hint: surface area vs. flow, i.e. overflow rate.) How would you check it in the field?
